# IIT_Mandi_S2F
Skull-to-face dataset contains X-ray images of Indian individuals and their corresponding faces ( face images are in vector representation). 128-dimensional face embeddings are obtained using the DeepFace Python library and the FaceNet deep neural network model.
# Academic and Research Use
This dataset is primarily intended for academic research, computer vision studies, machine learning applications, and educational purposes.
